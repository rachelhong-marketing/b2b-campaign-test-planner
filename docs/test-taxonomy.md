# Paid media test ideas

A list of things worth testing in B2B paid search and paid social, one variable at a time. Pick one idea, decide what stays the same, run it, and write down what you learned before you pick the next one. These are general test ideas, not results from any company.

| What to test | Paid search version | Paid social version | What to hold constant | Watch out for |
|---|---|---|---|---|
| Role or industry callout vs. general message | Role or industry named in the headline | Role or industry named in the intro text | Offer, landing page, budget | Small audiences; a callout can also change who clicks |
| Urgency vs. softer language | "Ends Friday" vs. "Available now" in headline or description | Same in intro text | Offer, audience | Fake urgency erodes trust; use real deadlines only |
| Curiosity vs. clarity | Question headline vs. plain benefit | Teaser image and headline vs. direct | Keywords or audience | Curiosity often lifts clicks but not qualified leads |
| Short vs. long copy | Shorter vs. fuller description | Short vs. long intro text | Everything else | Platforms truncate; check how it renders |
| Question vs. statement | Question headline vs. statement | Same | Everything else | Keep the claim the same, change only the form |
| Proof point vs. general claim | Stat or result vs. benefit | Same | Offer, audience | Make sure the proof is approved and sourced |
| Seasonal or timely angle | Event or season hook | Same | Offer | Short shelf life, so keep the test window short |
| Action vs. learn-more CTA | "Download the guide" vs. "See how it works" | CTA button text | Landing page | Match the CTA to the page |
| Formal vs. casual tone | Description tone | Intro text tone | Everything else | Brand rules apply |
| Naming the asset type (guide, report, webinar) vs. not | In headline | In intro text | Offer | Makes the offer clearer but can limit clicks |
| Analyst or third-party mention vs. none | Credibility line | Credibility line | Offer | Needs an approved source |
| Customer name vs. no customer name | Proof line | Proof line | Offer | Needs permission to use the name |
| Category vs. competitor-alternative keywords | Keyword set | n/a | Ads, landing page | Search terms are partly hidden, so test themes, not single words |
| Single image vs. document or carousel ad | n/a | Ad format | Copy, audience | Formats show in different places, so compare cost per lead, not just CTR |
| Person vs. product image | n/a | Creative | Copy, audience | Creative fatigue sets in fast with small audiences |
| Short vs. long lead form | Landing page form | Lead gen form | Ad, audience | More fields can lower volume but raise quality |
| Job titles vs. job function + seniority | Audience layer | Targeting | Creative, budget | Audience size changes, so check reach before launch |

## Rules for every test

1. One variable per test. Write down what you hold constant.
2. Write the hypothesis with a "because" before you launch.
3. Tag each version so results can be told apart (a variant tag in the tracking link).
4. The early read (clicks, click-through rate, leads) gives direction. The business metric (qualified leads, pipeline) decides.
5. Record the learning and the next test in the same row.

## Things to know about paid media tests

- **Volume is lower and more expensive than you'd like.** Use `planner size` before launching. If it says nine weeks, test a bigger change or read the result as direction only.
- **Platforms mix and hide things.** Some search ad formats rotate headlines automatically, and some search terms are hidden. Use the platform's own experiment feature or pin assets so the test is real.
- **Conversions are not the same as qualified leads.** A form fill is early. Sales qualification comes later. Plan the second read.
- **Audience and creative interact.** Don't change both in one test.
