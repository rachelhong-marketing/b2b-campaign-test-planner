# Test taxonomy: from email subject lines to paid media

Email teams already have a habit worth keeping: a list of things to test, one variable at a time, with a place to record what was learned. The same list works for paid media once each item is translated. These are generic test ideas, not results from any company.

| Email test idea | Paid search version | Paid social version | What to hold constant | Watch out for |
|---|---|---|---|---|
| Personalization vs. none (name in subject) | Account or industry named in the headline | Account-based audience with a matching message vs. broad message | Offer, landing page, budget | Small audiences; personalization can also change who sees the ad |
| Urgency vs. softer language | "Ends Friday" vs. "Available now" in headline or description | Same in intro text | Offer, audience | Fake urgency erodes trust; use real deadlines only |
| Curiosity vs. clarity | Question headline vs. plain benefit | Teaser image and headline vs. direct | Keywords or audience | Curiosity often lifts clicks but not qualified leads |
| Short vs. long | Shorter vs. fuller description | Short vs. long intro text | Everything else | Platforms truncate; check how it renders |
| Emoji vs. none | Not usually allowed | In intro text or headline | Everything else | Brand fit and audience seniority |
| Question vs. statement | Question headline vs. statement | Same | Everything else | Keep the claim the same, change only the form |
| Proof point vs. general claim | Stat or result vs. benefit | Same | Offer, audience | Make sure the proof is approved and sourced |
| Seasonal or timely angle | Event or season hook | Same | Offer | Short shelf life, so keep the test window short |
| Action-oriented vs. informative CTA | "Download the guide" vs. "See how it works" | CTA button text | Landing page | Match the CTA to the page |
| Tone: formal vs. casual | Description tone | Intro text tone | Everything else | Brand rules apply |
| Asset type mentioned (guide, report, webinar) vs. not | In headline | In intro text | Offer | Makes the offer clearer but can limit clicks |
| Humor vs. straightforward | Rarely worth it in search | In social | Everything else | Risky with senior B2B audiences |
| Analyst or third-party mention vs. none | Credibility line | Credibility line | Offer | Needs an approved source |
| Client name vs. no client name | Proof line | Proof line | Offer | Needs permission to use the name |
| Keyword theme (problem vs. solution words) | Keyword set | n/a | Ads, landing page | Search terms are partly hidden, so test themes, not single words |
| Image type (person vs. product) | n/a | Creative | Copy, audience | Platform fatigue |
| Audience (account list vs. broad) | Customer list or audience layer | Targeting | Creative, budget | Size and match rates change |

## Rules that carry over

1. One variable per test. Write down what you hold constant.
2. Write the hypothesis with a "because" before you launch.
3. Tag each variant so results can be told apart (a variant tag in the tracking link).
4. The early read (click-through, on-page conversion) gives direction. The business metric (qualified leads, pipeline) decides.
5. Record the learning and the next test in the same row.

## What changes in paid media

- **Volume is lower and more expensive.** Use `planner size` before launching. If it says nine weeks, test a bigger change or read the result as direction only.
- **Platforms mix and hide things.** Some search ad formats rotate headlines automatically, and some search terms are hidden. Use the platform's own experiment feature or pin assets so the test is real.
- **Conversions are not the same as qualified leads.** A form fill is early. Sales qualification comes later. Plan the second read.
- **Audience and creative interact.** Do not change both in one test.
